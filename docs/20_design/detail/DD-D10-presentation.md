## 1. snapshot の消費（確定。REQ-VIS-04、BD-05 §12.4）

- 描画は `kz_snapshot` のコピーアウト後のバッファのみを読む。`step` とバッファを共有しない（BD-11 §5 ADV-15）
- レイアウトは BD-05 §12.4 どおり（リトルエンディアン固定）。バッファ長は `16 + width × height × 96`（ヘッダの width/height を使う一般格子式。64×64 は検証版の既定値であり形式は 64×64 固定としない）。energy を含まない
- ヘッダ（16 B）のバイトオフセット: `width@0 (u16)`、`height@2 (u16)`、`n_lineages@4 (u8)`、`tick@5 (u32。非整列オフセット)`、`pad@9..15 (7 B、0 固定)`。Dart 側はこのオフセット表どおりに読む（tick を offset 8 に置く実装は 7 B パッドと矛盾するため禁止）
- セルレコード（96 B、row-major）のオフセット: `nutrient@0 (i64)`、`biomass@8..71 ([i64; 8])`、`carcass@72 (i64)`、`waste@80 (i64)`、`occupancy_peak@88 (i64)`。`biomass[8]` のうち `n_lineages` を超えるスロットは書き側（core）が 0 に固定し、読み側は描画しない
- 間引きフレームでは古いバッファを「新しい tick」として描画しない（前フレームの表示を維持する）。古いバッファの `header.tick` を表示クロックとして UI に出さない（表示 tick は UI 側が持つ最終確定 tick を使う）

## 2. 形状主・色補助の符号表（確定。REQ-VIS-01、v0.4 §1.7・付録 C）

| 系統 | 輪郭（主符号） | 塗り／色（補助） |
|---|---|---|
| アオシキ | 丸みのある塊 | 均一／青緑・中明度 |
| シロナミ | 細長い波型 | 横縞／明るい灰・高明度 |
| アカバエ | 角ばった粒の群れ | 密な点々／橙赤・中高明度 |
| クロシデ | 三日月／ギザ辺の帯 | 粗い斜線／炭色（純黒不可）・低明度 |

- 色を外しても 4 者が形で識別できることが受入条件（REQ-VIS-01 の INSP + USER）
- 環境（空き家ハッチ・waste・carcass）は「場」、系統は「形」として符号系を分ける。場の写像（確定）:
  - 空き家ハッチ: `occupancy_peak > 0` かつ現在のセル総 biomass = 0 のセルにハッチを重ねる（占有跡の可視化。occupancy_peak は snapshot のセルレコード由来）
  - waste / carcass: プール量を場のオーバーレイ濃淡に写像する。`min(pool, cap) / cap` で 0..1 に線形正規化して不透明度へ（cap は固定値。初期仮説: waste cap = 40_960_000 / 16 = 2_560_000、carcass cap = 2_560_000。較正で調整しうる）
  - 転換点スタンプの位置は snapshot に含まれず、LedgerSave / explain 経由（BD-12）で別途取得する（snapshot だけからは描けない）
- 通常表示は集団パッチ（セルの系統別 biomass を形状パッチの大きさに写像）。写像は線形 + clip で固定: 正規化量 `min(biomass, cap) / cap`（cap = 4_000_000 = 4.0 mass_u、初期仮説）をパッチ半径へ線形に写し、セル内接円を上限とする（スクリーンショット試験を割らないため対数・非線形は使わない）。重要イベント時のみ局所拡大
- 凡例は色名ではなく形状アイコン＋通称（v0.4 付録 C）

## 3. 表示用トークン（確定。REQ-VIS-03、v0.5 §1.4）

- 最大 8 個、生成は `tick % 5 == 0` の snapshot のみ、位置はセル中心
- 選出規則（確定。PRNG 非消費で一意に落ちる）: 候補は全セル × 全系統のうち `biomass[lineage] > 0` の組。比較キー = (biomass 降順、lineage id 昇順、cell_index 昇順) の辞書順で上位 8 件を選ぶ。biomass = 0 の組は候補から除外し、同率はキーで一意に決まる（core の乱数を借りる抜け穴を塞ぐため、このキー以外の選出は契約違反。REQ-OUT-04）
- ID = `系統 + セル + tick バケット` で揮発（生涯 ID を持たない）。tick バケット = `tick / 5`（整数除算。ゼロ方向丸めで非負なので floor と同値）
- 生成は snapshot バッファからの読取のみで、core の PRNG・状態を一切消費しない（REQ-OUT-04）
- 無効化フラグ `tokens_enabled` を config ではなく Presentation 側の表示設定とし、on/off で終了ラベル・state hash がビット一致（AT-D10-01 = D10 の完了判定「トークンを消しても終了ラベルがビット一致」。v0.5 §1.4）

## 4. 描画間引き（確定。REQ-VIS-04、BD-11 §2 #5）

- 間引きは `snapshot`・描画の省略のみ。`step` は上限まで実行し tick を破棄しない
- 間引きの有無はリプレイ経路（save・hash・イベント列）に載らない（AT-D10-02）
