## 1. スケジューラ（確定。REQ-CON-05、BD-11 §2 の 7 要素をそのまま実装する）

- 時計は `Stopwatch`（単調時計）。`DateTime.now` は tick 駆動・間引き判定・オートセーブ間隔のいずれにも使わない（REQ-CON-05、BD-11 §2。端末時刻改変で tick を飛ばさない）
- 速度（BD-11 §2 確定値）: **低速 1 / 標準 4 / 高速 16 tick/s**、一時停止は 0 tick/s。速度変更・一時停止は PRNG を消費しない
- 固定時間刻み（要素 2）: フレーム時刻 `t`・前フレーム `t0`・目標 `r` tick/s として **`due += r * (t - t0)`**。刻みは `r` の逆数に固定し、フレーム間隔の実測で `due` だけ積む
- フレーム実行上限（要素 3）: 1 フレームの `step` 合計は **低速 1 / 標準 1 / 高速 2**。残りは `due` に残す。`step(16)` のような一括実行は禁止
- 遅れ持ち越し（要素 4）: 上限で切り捨てた `due` は次フレーム以降に加算し、リセットしない
- 描画間引き（要素 5）: `due` が上限より大きいとき `step` は上限まで実行し、`snapshot` と描画を 1 フレーム省略可。tick は破棄しない（間引きは描画のみ。DD-D10 §4）
- 500 ms 自動一段下げ（要素 6）: 単調時計の累積遅れ ≥ 500 ms で **16→4、4→1**。1 のまま停止はしない（低速を維持し遅れを持ち越し）。手動で上げ直したら累積遅れを 0 に戻す
- 凍結（要素 7）: 一時停止・S-NOW/S-STAMP 表示中・OS 中断（inactive/paused/detached）のいずれかで `due` を積まない・`step` しない。再開時に単調時計の基準を引き直す（閉じた直後に `step` バーストしない）
- 検証ケースは BD-11 §2 の SCH-01..09（9 件）に従う。速度変更はスケジューラの速度変数を書き換えるだけで sim 状態に触れない

## 2. 画面状態機械（確定。BD-11 §1 の実装構造）

- BD-11 §1 の画面列挙（12 画面: S-BOOT / S-SETUP / S-HYPO / S-RELEASE / S-DISH / S-NOW / S-STAMP / S-CARD / S-CARDS / S-WHATIF / S-RETRY / S-ERR）を Dart の sealed class `AppScreen` に写す。遷移は BD-11 §1 の表どおりのみ許可し、表に無い遷移は静的に到達不能にする。sealed class のサブタイプが 12 画面を過不足なく列挙することを遷移表の網羅テストで検査する（UT-D12-03）
- 各画面の FFI 呼出は BD-11 §4 の順序表どおり。敵対シーケンスは AT-D12-ADV-01..20 として UI テストで全件実施する
- エラー表示: `KzError` を BD-11 §4.2 のメッセージ表に写像。`KZ_ERR_BUSY` はリトライ UI を出さず操作を無視（BD-11 §4）

## 3. 保存・中断再開の UI 手順（確定。REQ-UI-05、REQ-DET-07、DD-D8）

- 復帰の主機構（D12-Q1 裁定 2026-08-30）: **一時停止・バックグラウンド遷移・終了要求の各イベントで必ず `save` する**（BD-11 §3 RES の手順どおり）
- 保険のオートセーブ（D12-Q1 裁定で採用）: **60 秒周期**（Stopwatch ベース）。BD-11 S-DISH 行の「フォアグラウンド 50 tick ごと save（初期仮説）」は本節で置き換える（BD-11 §7 が確定先を D12 詳細設計と指定している）。保存コストは BD-09 の予算内: save は ≤ 5 MB（REQ-NFR-02）の atomic 書込みで 1 回あたり数 ms 級であり、60 秒周期ではバッテリ・I/O とも無視できる。実測で予算を超える場合は 120 秒に伸ばす（裁定の条件）
- 原子的書換えは DD-D8 §3 の手順を core 側が行い、UI は `kz_save` を呼ぶだけ
- 復帰: 起動時に `kz_load`。`KZ_ERR_SCHEMA` / `KZ_ERR_MODEL_VERSION` は DD-D8 §2 のメッセージを表示し新規開始へ誘導（BD-11 §3。S-ERR）
- 中断復帰の要件の引用は REQ-UI-05 / REQ-DET-07 とする（D12-Q1 裁定で引用訂正。REQ-ACC-02 はレバー設計の差し戻し基準であり本章の根拠ではない）
- 終了ラベル到達時は S-CARD へ遷移し、説明 4 段（DD-D9 §4）を表示（REQ-UI-07、REQ-EXP-01）
