# RFC-0001: 空間可変拡散（v0.4「片側の waste 拡散率を低く」）のストア版送り

- 起票: cursor-kimi、2026-08-30。D5-Q1 の Claude 裁定（採用: 4 環境とも一様 0.05）に伴う要件差分の記録
- 状態: 提案（オーナーマージ対象）

## 動機

企画書 v0.4 の local_waste 環境は「片側の waste 拡散率を低く」する空間可変拡散を想定しているが、DD-D2 の拡散モデルは環境内一様係数であり、空間可変化は拡散ループの契約変更・決定性の再検証・性能（NFR-01）の再測定を伴う。検証版のスコープ（REQ-SCOPE-01 の 4 環境・2,000 tick）に対して過大である。

## 変更

検証版では空間可変拡散を実装しない。local_waste の waste 偏在は初期分布（pool_distribution_maps）のみで表現し、拡散係数は 4 環境とも一様 0.05（biomass = 0）とする（DD-D5 §1/§2.3）。空間可変拡散はストア版の論点として送る。

## 影響分析（trace 逆引き）

- 要件: v0.4 §付録の local_waste 記述との差分。REQ-ENV-01..04（sign-off 済正本）は空間可変拡散を要求していないため REQ 変更なし
- 設計: DD-D2（一様係数モデル）・DD-D5 §2.3 はこの前提で確定済み。影響先の改訂なし
- テスト: AT-D5-03（7 フィールド schema）に影響なし

## 移行

ストア版で空間可変拡散を導入する場合: diffusion_coefficients をセル/領域可変にする契約変更（schema major）+ 拡散ループの決定性再検証 + NFR-01 再測定 + model_version bump + reference_scenarios 再選定（REQ-DET-09）が必要。

## ロールバック

本 RFC の取り下げ = 検証版への空間可変拡散の再導入。上記「移行」と同じコストが検証版工程中に発生する。
