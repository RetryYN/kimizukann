# ADR-0001 コア数値表現は i64 固定小数点（scale 1e6、中間 i128）

- 状態: 採用（2026-08-30、D0 で実装済み）
- 参照: REQ-CON-02, REQ-SIM-05/06/13, REQ-DET-03

## 文脈
決定性（三経路・クロス OS でビット一致）と保存則（余りを捨てない）が P0。浮動小数点は OS・CPU・コンパイラ最適化で結果が変わりうる。

## 選択肢
1. f64 + 丸め規則固定 → クロス OS 一致を保証できない（FMA、libm 差）
2. 任意精度整数 → 遅い、スマホで tick 予算を超える
3. **i64 固定小数点 scale=1e6、乗算中間 i128、ゼロ方向丸め、余りは主出力へ** → 採用

## 結果
- 6 桁小数で係数（0.70 等）を正確に表せる。総質量の上限は BD-06 で証明する
- 解析（z-score）は f64 でよいがコア状態へ逆流禁止（lint: sim-core で f32/f64 を disallow）
- 除算・乗算は必ず `fixed::*` ヘルパ経由。生の `*`/`/` は clippy 設定で警告
