# キミ図鑑 企画相談会 第2回 ラウンド2 — Codex回答

- 対象: `docs/相談会/第2回_統合案_v0.5.md`
- 役割: アイディア担当
- 結論: アイディアの意味と段階の仕分けは概ね妥当。ただし「培養皿を折る」と受入試験4環境は、単純な地形の一対一対応ではなく「地形＋環境ルール」のプリセットとして統合する必要がある。また、カード機能3件をすべて初期版必須にすると過積載になるため、候補内で優先順位を付けたい。

## 1. 2章・3章の仕分けへの回答

### 1.1 異論なし

- 「放つ前のひとこと仮説」を検証版へ入れる判断に異論はない。正解競争にせず、予想が崩れた転換点へつなぐ契約も意図どおりである。
- 「観察の約束」「培養皿を折る」「一セル顕微鏡」を初期版へ置く判断は妥当。ただし初期版の同一マイルストーンで全部を同時実装するのではなく、コアループ成立後に一件ずつ評価する。
- 「名付けは、系統になってから」を、分岐実装後の初期ストア版へ置く判断に異論はない。
- 「裏返し培養」「生命史の音」を後続へ送る判断に異論はない。
- seed A/B/Cを台本ではなく、発生率帯の中に現れる期待例として扱う判断に異論はない。実装前のseed番号ではなく、生命史パターンIDとして管理するのがよい。

### 1.2 軽微な修正: カード3機能を初期版の必須範囲へ一括追加しない

2.4の3件はすべてカードを見せたくするが、依存関係と検証目的が異なる。

1. **培養カプセル**: 最優先。再現契約そのものを外部で試せ、キミ図鑑固有の「相手も同じ生命史を走らせる」価値がある。
2. **観察者の付箋**: 次点。共有方法がOS標準共有の画像だけでも成立し、実装が軽い。
3. **三秒の転換標本**: 初期版候補に残すが必須にしない。状態再構成、表示用トークンの決定性、書き出し形式、端末間差という追加課題がある。

初期版のスコープ表には「カード共有拡張候補」として3件を置き、培養カプセルだけを先行受入対象にすることを提案する。コア育成を圧迫してまで三件を揃えない。

### 1.3 軽微な修正: 「環境札」と「地形札」の言葉を分ける

`center_rich / edge_sparse / local_waste / carcass_pulse` は、純粋な地形ではなく、初期物質構成や局所蓄積まで含む試験環境である。「地形札＝環境プリセット」と完全同義にすると、資源総量を変えず配置だけを変えるという元アイディアから外れる。

- 地形札: セル上の空間配置だけを決める
- 環境札: 地形に加えて初期4プール配分、waste蓄積、流入マスクを含む

初期版では操作UIを複雑にしないため、プレイヤーには一枚の「培養皿札」として見せてもよい。ただしデータ契約では `geometry_id` と `regime_id` を分離する。将来、同じ地形で環境ルールだけ変える比較に再利用できる。

## 2. 論点F — 地形札4枚と受入試験4環境

### 2.1 推奨対応表

| 受入試験ID | プレイヤー向け札名 | 基本地形 | 環境ルール・初期配分 | 主に試す系統 | 注意点 |
|---|---|---|---|---|---|
| `center_rich` | **中央の島** | 中央に大きな資源塊、外周は薄い | 通常資源の大半を中央へ置く。waste・carcassは少量 | アオシキ、アカバエ | アオシキの隠れた上位互換と、アカバエの過剰繁殖を検出 |
| `edge_sparse` | **縁の輪** | 外周に細く途切れた資源帯、中央は乏しい | 総資源量は中央の島と同じ。外周セル一つ当たりの密度を低くする | シロナミ | 「edge_sparse」は端に資源がない意味ではなく、端に**希薄な資源がある**と契約へ明記 |
| `local_waste` | **二つの池** | 二つの資源域を細い接続部で分ける | 一方はwaste拡散率を低くして局所蓄積しやすく、他方は通常。初期物質総量は揃える | 毒耐性差、分散、アオシキ | 地形だけでなく局所拡散係数を含むため `regime_id` が必要 |
| `carcass_pulse` | **死骸の回廊** | 細い回廊の一端に死骸域、他端に通常資源域 | 外部から死骸を追加せず、初期物質の一部をnutrientからcarcassへ移す。時系列パルスを試す場合だけ別の流入マスクを使う | クロシデ、アカバエ＋クロシデ | 「細い回廊」だけでは死骸利用試験にならない。物質種の初期配分を札の説明へ出す |

### 2.2 「資源総量を変えない」の修正

4枚すべてで同じにすべきなのは、通常資源 `nutrient` の量ではなく**初期物質総量**である。`carcass_pulse`だけ通常資源の一部を死骸へ振り替えないと、クロシデのニッチを試せない。

比較契約は次の二段階にする。

- 純粋な地形比較: 4プールごとの総量を固定し、セル配置だけ変える
- ニッチ受入試験: 初期物質総量を固定し、nutrient / carcass / wasteの配分と局所拡散を環境ごとに変える

プレイヤー向け札では「食べ物の合計」ではなく「皿にある物質の合計は同じ」と説明する必要はない。画面には「中央に食べ物が多い」「端に薄く広がる」「片側に汚れが残る」「死骸から始まる」の違いを短く示せばよい。

### 2.3 データ形

一対一対応を保ちつつ、内部では次のように分離する。

```text
environment_id
  geometry_id
  initial_pool_totals
  pool_distribution_maps
  diffusion_coefficients
  inflow_tick_mask
  expected_niche_tags
```

これにより、札は試験済みの環境プリセットを使いながら、将来は `geometry_id`だけを交換する実験もできる。

## 3. 論点H — 「心配なこと」の初心者向け選択肢

### 3.1 推奨6択

| 初見ユーザーに見せる文 | 内部で対応する主な理由コード・観測 |
|---|---|
| **食べ物を使い切りそう** | nutrient急減、摂取量過多、飢餓死増加 |
| **増えすぎて、あとで一気に減りそう** | 繁殖急増、維持不足、死亡急増 |
| **汚れがたまりそう** | waste蓄積、toxin_sensitive維持コスト増加 |
| **逃げる場所がなくなりそう** | 利用可能セル減少、分散不足、局所密集 |
| **死骸がうまく使われなさそう** | carcass蓄積、use_carcass系統の未到達・減少 |
| **みんな同じ場所に集まりそう** | 系統間の占有域重複、競争フロー増加 |

初回は6択を一度に文章だけで並べず、短いアイコンを添える。順序は、食べ物・増えすぎ・汚れ・逃げ場・死骸・場所の重なりとし、科学用語を避ける。

### 3.2 判定方法

「当たった／外れた」を内部理由コード一件へ単純に結びつけない。各心配へ観測条件を定義し、培養終了までに閾値を超えたかで判定する。

例:

- 「食べ物を使い切りそう」: 初期nutrientの一定割合以上を失い、かつ飢餓由来の死亡が発生
- 「汚れがたまりそう」: waste濃度が毒性閾値を一定期間超過
- 「みんな同じ場所に集まりそう」: 複数系統の高生体量セル重複率が閾値超過

終了時の表示は厳密な二択だけでなく、次の三段階がよい。

- **起きた**: 定義した観測条件を満たした
- **起きなかった**: 観測可能な時間があり、条件を満たさなかった
- **まだわからない**: 上限終了が早い、該当系統が先に絶滅したなど判定材料不足

「予想が外れた」よりも「今回は起きなかった」と表現すると、単一seedから一般法則を学んだと誤解させにくい。

### 3.3 初回チュートリアルでの出し方

固定seedの結果を知ったうえで正解選択肢へ誘導しない。6択はすべて常に同じ順序またはユーザーごとにランダム順で表示し、説明文の強調も揃える。チュートリアルseedで絶対に起きない項目があってもよい。目的は正解させることではなく、見る観点を一つ持たせることである。

## 4. 補足: seed A/B/Cの扱い

案Aベクトルへ差し替えたことで、seed Bの「アオシキ中央固定」が起きにくくなる可能性はある。しかし、3本は確定したseed番号ではなく期待する生命史パターンであるため、現時点で物語を書き換える必要はない。

較正後に次の順で扱う。

1. 案Aで4環境×100 seedを回す。
2. `center_rich`内から、アオシキ固定と説明根拠を満たすseedを探索する。
3. 発生率がゼロまたは極端に低い場合、物語のために勝者補正せず、アオシキのベクトルか環境条件を再検討する。
4. アオシキ中央固定を可能にすると上位互換試験へ違反する場合、seed Bをシロナミ外周固定など、モデルが自然に出す別の代表史へ置き換える。

代表史はモデルの振る舞いを説明する例であり、モデルを既存の筋書きへ従わせる要件にはしない。
