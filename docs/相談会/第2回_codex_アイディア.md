# キミ図鑑 企画相談会 第2回 — Codexアイディア案

- 対象: `docs/製品企画.md` v0.3、`docs/相談会/企画書_ブラッシュアップ案_v0.4.md`
- 役割: アイディア担当
- 方針: 既存の転換点スタンプ、生命史カード、もしもレバー、予感、空き家、比較画面を言い換えず、「仕込む・眺める・わかる」の循環へ新しい行為を加える。

## 1. 新しい体験アイディア

### 1.1 「放つ前のひとこと仮説」

- 一言タイトル: 予想を封じて、あとで開く
- 何が起きるか: 培養開始前に、プレイヤーが「最初に増える系統」「最後まで残る系統」「心配なこと」を各一つ選ぶ。予想は途中で採点せず、終了時に観測事実と並べて開く。正解数やランクは付けず、「当たった／外れた／まだ判定できない」と、その予想が崩れた最初の転換点を示す。
- 強める約束: **わかる**。結果説明を受け身で読む前に、自分の因果仮説を持たせる。
- 段階: **検証版**。選択式3問なら実装が軽く、面白さテストで「予想外だった」を直接測れる。

### 1.2 「観察の約束」

- 一言タイトル: 今回は、ひとつだけ見届ける
- 何が起きるか: 開始時に「アカバエの最初の減少」「最初に空く場所」「最初に死骸を使う系統」など、観察対象を一つ選ぶ。その出来事が近づいたら速度を一時的に落とし、皿の該当領域を静かに縁取る。結果を誘導せず、見逃しだけを減らす。
- 強める約束: **眺める・わかる**。複雑な全体から、初心者が見る対象を自分で一つ選べる。
- 段階: **初期版**。転換点検出のイベント種別を利用できるが、既存スタンプとは「事後の記録」ではなく「事前に選んだ観察対象」という点が異なる。

### 1.3 「名付けは、系統になってから」

- 一言タイトル: 生き残った歴史に名前を贈る
- 何が起きるか: 初期4系統の通称はそのまま使い、突然変異クラスターが分岐条件を満たしたときだけ、プレイヤーが新しい系統へ短い呼び名を付けられる。見た目や能力を直接作る機能ではなく、成立済みの生命史へラベルを残す。絶滅した分岐候補には命名せず、「名もない枝」として系統樹へ残る。
- 強める約束: **眺める**。創発したものへの愛着を、キャラクターメーカー化せずに作る。
- 段階: **初期版**。系統分岐の判定が安定した後に入れる。

### 1.4 「一セル顕微鏡」

- 一言タイトル: 数字ではなく、受け渡しを見る
- 何が起きるか: 培養皿の一セルを長押しすると、その場所で栄養資源が生体量へ変わり、死骸・老廃物へ流れる様子を数秒の簡略アニメーションで見られる。個体の臓器を描くのではなく、4プール間の受け渡しと各系統の取り分を表示する。通常画面へ戻ると時間も元に戻る。
- 強める約束: **わかる**。フロー台帳をグラフではなく、局所の出来事として理解できる。
- 段階: **初期版**。まず主要転換点の前後だけを再生し、常時ライブ計算はしない。

### 1.5 「裏返し培養」

- 一言タイトル: 名前を隠して、ふるまいから見抜く
- 何が起きるか: 一度通常培養を終えたあと、4系統の名前と札を伏せた短い培養に挑める。動き、資源の減り方、排出、死骸利用から、どれがアオシキ等かを途中で推理する。終了後は答えと、判断材料になった観測事実を示す。能力を暗記させるクイズではなく、表現から状態を読めるかの確認になる。
- 強める約束: **眺める・わかる**。見た目の可読性そのものを遊びにする。
- 段階: **後続**。学習モードではなく、育成体験を深める短い派生遊びとして扱う。

### 1.6 「培養皿を折る」

- 一言タイトル: 同じ資源を、違う地形にする
- 何が起きるか: 資源総量を変えずに、配置だけを「中央の島」「縁の輪」「二つの池」「細い回廊」へ組み替えられる。資源を増やして有利にする操作ではなく、同じ総量の空間構造を変える。皿を選んだ瞬間に、各系統の開始位置との相性が図形で読める。
- 強める約束: **仕込む**。数値調整ではなく、空間配置そのものを実験条件にする。
- 段階: **初期版**。最初は4種の固定地形札に限定する。

### 1.7 「生命史の音」

- 一言タイトル: 皿を見ていない瞬間も、異変が聞こえる
- 何が起きるか: 系統ごとに楽器を割り当てるのではなく、繁殖は細かな脈、資源枯渇は音の間引き、老廃物蓄積は濁り、死骸利用は低い反復音として鳴らす。音だけで系統を識別させず、状態変化を補助する。終了カードには最大転換点前後の数秒だけ「音の標本」を添えられる。
- 強める約束: **眺める**。視覚以外にも生命史のテンポと崩れを感じられる。
- 段階: **後続**。アクセシビリティと演出の両面で検証する。常時音を前提にせず完全にオフにできる。

## 2. 100世代で起きる代表的な生命史

三本は同じ基本条件を使い、seedだけで結末が分かれる想定とする。

### 共通初期条件

- 地形: 中央に濃い通常資源、外周に薄い資源、北東に老廃物が溜まりやすい窪地
- 配置: アオシキは中央西、アカバエは中央東、シロナミは外周南、クロシデは北東端
- 個体数: アオシキとシロナミは標準、アカバエは少数、クロシデは最少
- 観察上限: 100世代相当

### 2.1 seed A — 赤の急増、黒の継承、白の帰還

1. **12世代相当**: アカバエが中央資源へ先着し、4系統で最初の急増スタンプが付く。
2. **27世代相当**: 中央東の通常資源が急減し、アカバエの老廃物排出と死亡が増える。
3. **41世代相当**: クロシデが死骸の多い北東から中央へ帯状に広がり、開始時生体量を初めて上回る。
4. **66世代相当**: シロナミが外周の薄い資源をつないで生存域を広げ、中央の空き家へ戻る。
5. **100世代相当**: シロナミとクロシデが別ニッチで共存。アカバエは絶滅、アオシキは少数残存。

- カードタイトル案: **「シロナミとクロシデ、百世代で二域に残存」**

### 2.2 seed B — 青の中央固定、白の外周残存

1. **9世代相当**: アオシキが中央西から資源密集域を確保し、アカバエとの境界が生まれる。
2. **21世代相当**: アカバエは局所的に増えるが、繁殖がばらつき、中央全域を覆う前に死亡が増える。
3. **38世代相当**: アオシキが空いた中央東へ低速で広がり、中央生体量の過半を占める。
4. **59世代相当**: クロシデは利用できる死骸の連続帯を作れず絶滅。シロナミは外周南へ残る。
5. **100世代相当**: アオシキが中央で固定、シロナミが外周に小集団を維持する。

- カードタイトル案: **「アオシキ、中央六割で固定」**

### 2.3 seed C — 四系統の連鎖衰退と全滅

1. **14世代相当**: アカバエの増殖域とアオシキの摂取域が重なり、中央資源の減少がseed A・Bより早く始まる。
2. **31世代相当**: アカバエが急減。死骸が増える一方、北東の老廃物濃度も上昇する。
3. **48世代相当**: クロシデが一時増加するが、利用可能な死骸帯が途切れ、次の領域へ届かない。
4. **72世代相当**: 外周資源へ移動したシロナミとアオシキが同じ南側領域で競合し、両方が減少する。
5. **93世代相当**: 最後のシロナミ小集団が消え、死骸と利用されない資源が異なる領域に残る。

- カードタイトル案: **「九十三世代で四系統が消失」**

### 三本を並べたときに伝わること

- seed Aではアカバエの大量死がクロシデの足場になり、seed Bでは死骸の空間的な連続ができずクロシデが消える。
- seed Bではアオシキが中央を押さえるが、seed Cではアカバエとの初期接触位置が少し違い、資源消費が早まる。
- seed Cの全滅は「資源総量がゼロ」ではなく、必要な系統と利用可能資源が空間的に出会えなかった結末である。
- 三本とも固定イベントを使わず、初期の移動方向・繁殖・変異の乱数差が、空間配置を通じて増幅した結果として説明できる。

## 3. 生命史カードを人に見せたくなる工夫

### 3.1 「培養カプセル」— 相手が同じ皿を開ける短い実験コード

カードへ、初期条件・モデル版・seedをまとめた短いコードまたはQRを付ける。受け取った人は同一モデル版が端末にあれば、アカウントやクラウドなしで同じ培養を再生できる。さらに「seedだけ変える」「光っている一レバーだけ変える」のどちらかを選んで返せる。

見せるだけの画像から、「同じ条件を相手の端末で確かめられる招待状」になる。コードにはモデル版を含め、旧版は再生不可または現行モデルでの再解釈であることを明示する。

### 3.2 「三秒の転換標本」— 一番大きな変化だけが動く

カード表を長押しすると、最大転換点の直前1秒・転換1秒・直後1秒だけが無音または環境音付きでループする。新しい動画を編集する機能ではなく、保存済み集計と表示用トークンから自動再構成する短い動く標本である。

静止画では伝わりにくい「赤い領域が崩れた直後、暗い帯が入り始める」といった変化を一目で共有できる。本格動画制作やCreator機能には踏み込まない。

### 3.3 「観察者の付箋」— 事実と自分の仮説を一緒に渡す

共有前に、プレイヤーが一文だけ付箋を添えられる。自由な科学的断定に見えないよう、付箋には必ず次のラベルを選ぶ。

- 「ここを見て」— 観察してほしい転換点
- 「私はこう予想した」— 開始前に封じた仮説
- 「次はこれを試したい」— 次の実験案

付箋はシステムの説明欄と視覚的に分け、「プレイヤーのメモ」と表示する。カードを見た相手が結果だけでなく、持ち主が何に驚き、何を確かめたいかまで受け取れる。

## 4. 優先提案

第2回で一つだけ追加するなら、検証版へ「放つ前のひとこと仮説」を入れる。実装が小さく、キミ図鑑の独自価値である「結果を読んで再実験する」を強め、ユーザーテストでも予想と驚きの差を測れるためである。

初期版では「培養皿を折る」と「一セル顕微鏡」が有力である。前者は仕込む選択を数値以外へ広げ、後者は複雑な物質循環を手触りのある理解へ変える。カード共有は、オンライン基盤を必要としない培養カプセルから始めるのが製品原則と整合する。
