## 1. 体験を面白くするアイディア

### 1. ニッチの空き家が見える

- 何が起きるか: ある系統が減ると、その場所の色が「誰も使っていない資源帯」として薄く残る。プレイヤーは空き家を見て、次に誰が入るか予想する。
- 強める約束: 眺める（空間の変化が物語になる）、わかる（逆転の予兆を自分で読める）
- 入れる時期: 初期版。検証版でも、優勢種の衰退が見える材料になる。

### 2. 適応方針は『長所1・短所1』の札

- 何が起きるか: 高速移動なら「届くが飢える」、死骸利用なら「平時は遅いが、死んだあとに強い」。札を選ぶ行為自体が仕込みになる。上位互換の札は置かない。
- 強める約束: 仕込む（限られた条件で戦略を組む）
- 入れる時期: 初期版。企画 4.2 の具体化。

### 3. 転換点スタンプ

- 何が起きるか: 急増、枯渇、初捕食、死骸逆転、絶滅の瞬間に、培養皿へ小さなスタンプが残る。再生するとスタンプ順に物語が辿れる。グラフを開かなくても「いつ ram が折れたか」が残る。
- 強める約束: 眺める、わかる
- 入れる時期: 初期版。生命史カードの転換点と直結させる。

### 4. 一つだけ変える『もしもレバー』

- 何が起きるか: 終了画面の「次の一手」が、個体数・配置・適応方針・ばらつきの四つのレバーのうち一つだけ光る。複数同時変更は初期はできない。
- 強める約束: わかる（原因を自分で確かめる）、仕込む（次の実験がすぐ始まる）
- 入れる時期: 初期版。企画 4.7 の操作化。

### 5. 全滅はエンディングの一種

- 何が起きるか: 全滅時も「失敗」画面にせず、最後の死骸がどう流れたか、誰が最後まで残ったかをカード化する。再実験ボタンが一番大きい。
- 強める約束: わかる（失敗を情報にする）、眺める（終わり方にも物語がある）
- 入れる時期: 初期版。

### 6. 同じ皿、違う偶然

- 何が起きるか: 条件は同じで seed だけ変えた二枚のカードを並べ、「同じ仕込みなのに片方だけ逆転した」と見せる。科学結論は出さない。偶然の幅を体感する。
- 強める約束: わかる（単一結果を断定しない）、眺める
- 入れる時期: 初期版は「別seedでもう一度」まで。並べて比較する画面は後続の実験モード寄りだが、カード二枚を図鑑で隣に置けるだけなら初期でも可。

### 7. 小声の予言（断定しない）

- 何が起きるか: 放つ直前に、系統の札から「起きやすそうなこと」を一つ、仮説ラベル付きで出す。「突出型が先に増えるかも（簡略モデル）」のように、事実ではないと明示する。当たっても外れても、あとでカードと照合できる。
- 強める約束: 仕込む（仮説を持って放つ）、わかる（事実と推論を分ける練習）
- 入れる時期: 検証版のあと、初期ストア版の候補。初回チュートリアルを邪魔しないなら初期に入れてよい。

### 8. 図鑑の背表紙は『自分の実験の癖』

- 何が起きるか: カードが溜まると、「死骸利用をよく選ぶ」「配置を端に寄せがち」など、プレイヤーの仕込み癖が背表紙に出る。ランキングや最強記録にはしない。
- 強める約束: 仕込む（自分の戦略が見える）、わかる
- 入れる時期: 後続。カード蓄積が先。

## 2. 4系統の具体案

プリセット「安定型2、突出型1、意図的劣位型1」に合わせる。名前は図鑑カード用の短い通称。実在種の精密再現ではない（簡略モデル）。

### アオシキ（安定・堅実摂取）

- 強み: 普通の栄養をそこそこ効率よく取る。維持コストが低い。個体は長く、増減が穏やか。
- 代償: 移動が遅い。死骸はあまり使えない。栄えた場所から出られない。
- 100世代のドラマ: 序盤は地味に増える。突出型が暴れたあと、空いた中央の栄養帯にじわじわ戻る。固定しやすいが、毒化が進むと逃げられずまとめて減る。

### シロナミ（安定・分散配置向き）

- 強み: やや遠くまで散れる。資源が偏っていても端の薄い帯で生き延びる。
- 代償: 摂取効率はアオシキより劣る。個体あたりの維持がやや高い。群れが薄い。
- 100世代のドラマ: 中央の争いに負けて端へ逃げる。全滅しそうに見えて、端の残りかすで細々と続く。seed によっては「避難所」になり、中央が死んだあと戻って固定する。

### アカバエ（突出・早期繁殖）

- 強み: すぐ増える。短い世代で場所を占有する。序盤の画面を塗りつぶす。
- 代償: 個体が脆い。消費が激しい。死ぬと死骸と老廃物が一気に出る。
- 100世代のドラマ: 最初の20世代で「勝ち」に見える。資源を食い尽くし、自分の排出で場を汚す。急減は転換点スタンプの定番。死骸をクロシデに渡す役でもある。常勝にはしない。

### クロシデ（意図的劣位・死骸利用）

- 強み: 生きた栄養の取り合いでは最弱。死骸と老廃物を資源にできる。他が死んだあとに強くなる。
- 代償: 平時の増殖が遅い。死骸が少ない序盤はほぼ増えない。プレイヤーからは「負け系統」に見える。
- 100世代のドラマ: 序盤は隅でじっとしている。アカバエの崩壊後、黒い帯が死骸の上を歩く。逆転が起きれば図鑑の見せ場。死骸が少なければ細ったまま絶滅し、それも説明可能な終わり。

相互作用の狙い（作為イベントではなく、条件から起きてほしいこと）。

- アカバエ繁栄 → 資源枯渇と排出 → アオシキ衰退 → クロシデ逆転
- シロナミが端で生き残り、中央全滅後に戻る
- seed によって、クロシデ固定、四者細々共存、早期全滅が分かれる

## 3. 生命史カードを見せたくなる工夫

カードはキャラ絵の収集ではなく、自分の実験の一枚絵である。共有は初期必須ではないが、見返したくなる形は初期から入れる。

### 3.1 表は『一枚の培養皿写真』、裏は転換点

表は終了直前の培養皿を、系統色と空き家と死骸だけ残した静かな絵にする。裏をめくるとスタンプ順の三〜五個の転換点。SNS用の完成イラストではなく、その回だけの地図。友達に見せるときは「この黒いのが後から来た」と指差せる。

### 3.2 タイトルは自動の短い生命史

「アカバエ、二十世代で自滅」「隅のシロナミだけが残った」「クロシデ、死骸の上で固定」。スコアやSSSランクは付けない。タイトルが物語のフックになり、図鑑一覧で目が止まる。断定しすぎる科学表現は使わず、観測した出来事だけを短くする。

### 3.3 次の一手がカードの続きになる

カード下部に、まだ押していないレバーを一つだけ置く。「配置だけ端に寄せて再試行」など。見せる対象は完成品ではなく、続きのある実験。二枚目が隣に並んだとき、差がタイトルに出る（同条件・別seed / 一つだけ変更）と、図鑑がシリーズになる。
