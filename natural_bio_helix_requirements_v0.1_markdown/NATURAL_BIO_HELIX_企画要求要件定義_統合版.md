# Part I 企画書

## 1. エグゼクティブサマリー

本製品は、複数の初期個体群を設計して環境へ放ち、自然淘汰、突然変異、収斂進化、資源競争、捕食、社会性、死骸利用、環境改変を経て、どの形質が世代を越えて系統固定されるかを観察する生命シミュレーション・サンドボックスである。プレイヤーは完成した生物を直接作るのではなく、**進化可能な初期条件を設計し、生命史の結果を読む**。

同一環境では形態が収束しやすい一方、初期個体数、配置、偶然、資源の偏在、社会性、死骸、共生等により、4系統が20系統へ分岐することも、全て絶滅することもある。ゲームの達成条件は『一番強い個体』ではなく、形質が複数世代へ遺伝・再発現し、繁殖集団とニッチを持つ**系統固定**である。

## 2. 製品ビジョン

- 生物法則をクラフトする『生物版マインクラフト』。
- 強さを上げる育成ではなく、環境・資源・相互作用から生命史を生成する。
- 育成から学習、実験、研究へ同じ世界データで深掘りできる。
- ログが解説、動画、UGC、再実験、監査の共通資産になる。
- HELIXがAI実装と要求追跡を担う最初の商用リファレンス製品となる。

## 3. コア体験

1. 環境と資源を読む。
2. 複数系統と各系統の個体数・配置・遺伝的ばらつきを設計する。
3. コドンパズルまたは詳細編集で、輸送、代謝、繁殖、社会性等の『布石』を仕込む。
4. 個体群を環境へ投入する。
5. 数世代から数百世代を進め、予想外の相互作用を観察する。
6. 安定後に世代評価し、系統固定・分岐・衰退・絶滅を判定する。
7. 『今どうなってる？』で因果を読み、次の実験を設計する。
8. 生命史を動画・もしもシリーズとして共有・販売する。

## 4. 差別化

- 1体ではなく**複数個体群**を設計する。
- 見た目のパーツ付けではなく、物質取り込み、代謝、維持コストから表現型が生まれる。
- 繁栄が資源枯渇や環境毒化を起こし得る。
- 死・廃棄物・劣位形質が新しいニッチを生む。
- 固定科学法則と、未確定仮説を世界ルールとして分離する。
- ログ駆動の解説と動画制作を標準装備する。
- ユーザー作成の思考実験を市場化する。

## 5. ターゲット

- 思考型シミュレーションに没頭する成人。
- 生物・化学・進化・宇宙のサイエンス動画視聴者。
- 育成・自動化・サンドボックス・戦略ゲーム愛好者。
- 教育者・学生（学習モード以降）。
- 配信者・動画クリエイター。
- 後期の研究者・科学コミュニケーター。

## 6. 四モード

### 6.1 育成モード
直感的なコドンパズル、色・アイコンによる資源と状態表示、短い原因説明を中心とする。

### 6.2 学習モード
同じ現象を膜輸送、代謝、ATP、遺伝、自然選択等へ分解し、年齢・知識に応じて説明する。

### 6.3 実験モード
対照群、条件固定、複数seed、仮説差替、グラフ、系統樹、原因比較を提供する。

### 6.4 研究モード
専門家監修後に、方程式、solver、外部モデル、パラメータ推定、研究形式出力を提供する。

## 7. 収益モデル

- 本体または基本無料＋コア育成体験。
- Creator/Researcher/Developerの機能解放型サブスクリプション。
- 長期・多seed・動画高品質レンダリングの演算クレジット。
- ユーザー作成『もしもシリーズ』の販売と作者分配。
- 公式・監修済み天体、進化仮説、教育、研究パック。
- 学校・法人・研究コミュニケーション向けライセンス。

## 8. マーケティングループ

実験ログから『最弱系統が祖先になった』『増えすぎて全滅した』『氷中で絶滅種が残っていた』等の動画企画を生成する。動画コメントを再実験チケットへ変換し、続編を作る。ゲームを知らない視聴者にも題材だけで伝わることを狙う。

## 9. 初期製品の定義

最初から宇宙・動物・研究・Unityを作らない。最初の製品検証は、**2D培養皿に4系統を放ち、100世代後の系統固定または全滅を説明できるWeb実験玩具**である。

実験 → 見どころ抽出 → ナレーション → 動画 → もしもパッケージ → 販売。

### 12.4 研究利用者（後期）
モデル選択 → 詳細実験 → solver実行 → 不確実性比較 → 外部形式出力。

# Part IV シミュレーションコア詳細要件

## 20. コア設計原則

1. 強さではなく物質・エネルギー・繁殖の因果で結果を出す。
2. 1個体ではなく複数個体群と系統史を主語にする。
3. 同一環境では基本形態を収束させつつ、系統差と偶然を残す。
4. 固定は複数世代・繁殖集団・遺伝・再発現で判定する。
5. 死と排出を消さず、新資源とニッチにする。
6. 生物が環境を変え、次の淘汰圧を作る。
7. 詳細計算は関心領域だけ、遠方は集約する。
8. 説明可能なイベントと決定論リプレイを標準とする。

## 21. 状態モデル

### 21.1 World
seed、固定法則版、仮説プロファイル、時間、計算予算、スケール状態を持つ。

### 21.2 EnvironmentRegion
空間境界、物質量、温度、pH、酸素、光、圧力、流入出、隣接を持つ。

### 21.3 Individual / Cohort / Lineage
個体は詳細状態、cohortは代表状態と分散、lineageは遺伝・表現・繁殖互換と系統史を持つ。

### 21.4 Genome / Phenotype
ゲノムはコドン・遺伝子・制御・変異特性、表現型は環境下で発現した機能・形態・コストである。

### 21.5 Event / Summary
イベントは観測差分と根拠、サマリーは複数イベントを時間・系統・世界単位で圧縮する。

## 22. 環境化学

環境を単一の栄養値に縮退しない。各物質は量、元素、相、拡散、毒性、膜透過、反応性を持つ。生物は輸送体・膜・酵素がなければ利用できない。経路途中の物質も残り、蓄積すれば毒性や浸透圧へ影響する。

## 23. 進化・系統固定

固定候補形質は、発現個体数だけでなく、遺伝率、子孫再発現、繁殖成功、複数世代存続、ニッチ独立性、環境変動耐性を満たす必要がある。形態収束と遺伝的冗長性は両立可能とする。

## 24. 生態相互作用

捕食、死骸利用、排出物利用、共生、寄生、社会性を、固定職業ではなく資源フローと行動結果から判定する。『劣位』設計が別資源相で優位になることを許容する。

## 25. スケールと科学LOD

- 細胞: 輸送、代謝、ATP、発現、分裂。
- 組織: 輸送能力、接着、信号、分化、修復。
- 個体: 器官予算、行動、感覚、繁殖。
- 生態系: cohort、食物網、物質循環。
- 天体: 大気・海洋・地殻・熱・放射・不確実性。

現在スケールを詳細にし、外部スケールは保存則を保った集約値で更新する。

## 26. 計算最適化

- Signature batching: 環境・ゲノム・発現・内部状態bucketが同じ個体を一括計算。
- Memoization: モデル版を含む入力hashで結果再利用。
- Cohort aggregation: 遠方・安定個体を代表値と分散で扱う。
- Adaptive regions: 均一環境を統合し、変化箇所だけ分割。
- Multi-rate ticks: 重要度・距離・イベントで更新頻度を変更。
- Promotion/demotion: 特殊個体を個別計算へ昇格し、安定後にcohortへ戻す。

## 27. 生命起源・天体・仮説層

生命起源は正解を断定せず、複数仮説をルールプロファイルとして扱う。観測値・推定値・仮説値を分け、アミノ酸投入が生命を保証しない。天体全体は集約し、局所の熱水域、氷下海、クレーター等だけを詳細化する。

## 29. 基準シナリオ

### SCN-001 スカベンジャー逆転

**目的:** 突出系統が捕食され、意図的劣位系統が死骸利用で固定される。

**初期条件:** 安定系統A/B / 突出系統C / 低成長スカベンジャー候補D / 有限資源

**必須性質:** Cが必ず勝つような固定適応度を持たない / 死骸物質がDへ流れる / D固定または全滅の両方がseedで起こり得る

**関連要求:** FR-022, FR-021, SIM-006, SIM-020

### SCN-002 繁栄から全滅

**目的:** 個体数急増が資源枯渇と廃棄物蓄積を起こし全滅する。

**初期条件:** 高繁殖系統 / 有限再生資源 / 分解速度低

**必須性質:** 資源なし増殖禁止 / 全滅が正常終端 / 原因イベントが記録される

**関連要求:** FR-033, SIM-003, SIM-015, FR-049

### SCN-003 4系統から20系統

**目的:** 空間・食性・交配・突然変異により多数系統へ分岐する。

**初期条件:** 4系統 / 複数資源帯 / 移動障壁 / 変異有効

**必須性質:** 系統分岐が遺伝・繁殖互換差に基づく / 同一表示形質でも遺伝経路差を保持

**関連要求:** FR-027, SIM-014, UR-006

### SCN-004 社会性の固定

**目的:** 単独では弱い系統が協力・警戒・役割分担で固定される。

**初期条件:** 高捕食圧 / 協力候補系統 / 血縁識別

**必須性質:** 個体繁殖数だけで淘汰を決めない / 集団利益が系統頻度へ反映

**関連要求:** FR-020, SIM-022

### SCN-005 酸素革命

**目的:** 酸素発生系統の繁栄が嫌気系統を淘汰し、好気系統を生む。

**初期条件:** 嫌気生命圏 / 酸素発生系統 / 酸化sink

**必須性質:** 酸素は生成とsinkの収支で蓄積 / ティッピング後に環境転換

**関連要求:** FR-025, FR-034, SIM-031

### SCN-006 氷中残存と再放散

**目的:** 表面絶滅後に氷中避難所系統が再出現する。

**初期条件:** 全球凍結 / 塩水ポケット / 低代謝系統

**必須性質:** 観測ゼロと真絶滅を区別 / 避難所条件が物理値から成立

**関連要求:** FR-026, FR-028, SIM-032

### SCN-007 生命前化学の停止

**目的:** アミノ酸投入が生命を保証せず、高分子化または区画化で停止する。

**初期条件:** 天体局所環境 / アミノ酸 / 触媒有無の比較

**必須性質:** 自然発生非保証 / 段階状態と停止理由を記録

**関連要求:** FR-035, SIM-029

### SCN-008 仮説世界比較

**目的:** 漸進型と断続平衡型で同一初期条件の生命史を比較する。

**初期条件:** 同一seed集合 / 仮説のみ差替

**必須性質:** 固定法則は同一 / 仮説差分が説明可能

**関連要求:** FR-037, FR-039, SIM-027, SIM-028

### SCN-009 上位ステージ前提

**目的:** 複数の固定単細胞系統が協調しない限り多細胞化できない。

**初期条件:** 代謝/接着/信号系統 / 固定状態の組合せ

**必須性質:** 単一系統のみでは解放不可 / 相補機能の欠落理由を説明

**関連要求:** FR-031, SIM-033

### SCN-010 同一条件のseed差

**目的:** 同一設計でも初期接触と創始者効果で異なる歴史が生じる。

**初期条件:** 同一世界設定 / 複数seed

**必須性質:** 同seed再現 / 別seedで合理的差 / 差の転換点をサマリー

**関連要求:** FR-047, SIM-025, SIM-026, FR-051

# Part VII データ・API・運用

## 35. 主要データ

World、LawProfile、EnvironmentRegion、Substance、Reaction、Genome、GeneBlock、Phenotype、Individual、Cohort、Lineage、Event、Summary、SimulationRun、ScenarioPackage、VideoTimeline、Entitlementをversioned schemaで管理する。

## 36. セーブとログ

セーブは世界状態、seed、モデル版、cohort、重要個体、イベントoffsetを持つ。ログはイベントソーシングに近いappend-only構造とし、検索用projectionを別に持つ。

## 37. ローカル／クラウド分担

- ローカル: MVP、編集、短期シミュレーション、基本解説、ローカル保存。
- クラウド: 長期世代、複数seed、天体、動画高品質レンダリング、マーケット統計。
- 共通: 同一モデル版・seed・イベントschema。

## 38. セキュリティと法務

一般UGCは宣言的データのみ。決済、作者分配、音声録音、YouTube、未成年、科学表示は各リリースの法務ゲートとする。研究モード前は科学的結論を断定しない。

# Part VIII 検証・受入

## 39. テスト階層

- Unit: 反応、輸送、変異、固定判定。
- Property: 保存則、正規化、決定論。
- Mutation: チェック削除や符号反転をkill。
- Scenario: SCN-001〜010。
- Performance: 個体数、物質数、region数、イベント数。
- E2E: Web、モバイル、動画、UGC。
- Human playtest: 再実験意欲と結果理解。
